<a id="python"></a>
### Python

大部分 CTF 脚本、解题工具都是 Python 写的，这是**第一优先级**。

1. 官网下载：https://www.python.org/downloads/ （Windows 安装时**务必勾选 Add python.exe to PATH**）
2. 验证：打开终端输入 `python --version`，能输出版本号即成功
3. pip 换国内源（下载快很多）：
   ```powershell
   pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple
   ```
4. 常用库一把装：
   ```powershell
   pip install requests pycryptodome pwntools z3-solver pillow numpy
   ```

>  **详见《python引入.md》**：装完环境后可以跟着它过一遍——`bytes` 与编码(encode/decode/hex/base64)、异或 XOR 解密、正则提取 flag、文件读写、`requests` 请求。


<a id="c-语言gcc"></a>
### C 语言（gcc）

- 搭配《C语言引入》食用，验证命令：
  ```powershell
  gcc --version
  ```

>  **详见《C语言引入.md》**：如果 `gcc --version` 报"不是内部或外部命令"，99% 是 PATH 没配好，跟着文档重配；配好后写第一个 `hello.c` 跑通，再学编译参数（`-Wall`/`-g`/`-lm`）和报错速查表。想打 Pwn/Reverse 的话，**指针和内存布局**务必吃透。

## 终端入门

图形界面点按钮固然很好，但**服务器、靶机、容器没有图形界面**，你只能靠命令行。这是逃不掉的，所以早点习惯()。

<a id="windows-终端"></a>
### Windows 终端

- 推荐用 **Windows Terminal**（微软商店可装，比自带 cmd 好看好用）
- 常用命令：

```powershell
cd 目录名        # 进入目录
cd ..            # 返回上级
dir              # 列出文件（Linux 里是 ls）
mkdir 名字       # 新建文件夹
type 文件.txt    # 查看文件内容
del 文件         # 删除文件
cls              # 清屏
echo 文字        # 输出文字
```

<a id="什么是-path-环境变量"></a>
### 什么是 PATH 环境变量

当你敲 `python` 能直接运行，是因为系统在 **PATH** 里找到了 `python.exe`。
配置环境变量：`Win 键` → 搜索"环境变量" → 编辑用户变量里的 `Path`。
**装软件报"不是内部或外部命令"时，99% 是 PATH 没配好。**

<a id="终端使用小技巧"></a>
### 终端使用小技巧

- `Tab` 键自动补全路径
- 上下方向键翻历史命令
- `Ctrl + C` 强制终止当前程序

## Linux

**为什么必须学 Linux？** 因为互联网上绝大多数服务器跑的是 Linux，CTF 的 Pwn/Reverse 靶机也基本都是 Linux，Kali Linux 更是安全工具全家桶。

<a id="wsl2windows-自带的-linux-子系统"></a>
### WSL2（Windows 自带的 Linux 子系统）

最简单的方法，不用装虚拟机，只要一条命令：

```powershell
wsl --install
```

装完重启，默认装 Ubuntu，开始菜单里点开就是 Linux 终端。

<a id="linux-基础命令和-windows-对照着记"></a>
### Linux 基础命令（和 Windows 对照着记）

| Linux | 作用 | Windows 对应 |
|---|---|---|
| `ls` | 列出文件 | `dir` |
| `cd` | 进入目录 | `cd` |
| `cat` 文件 | 查看文件 | `type` |
| `pwd` | 当前路径 | `cd`（无参数） |
| `mkdir` | 新建文件夹 | `mkdir` |
| `rm` | 删除 | `del` |
| `sudo` | 以管理员运行 | 右键"以管理员身份" |
| `grep` | 搜索文本 | `findstr` |
| `chmod` | 改权限 | （无直接对应） |

<a id="一个测试在-wsl-里输入"></a>
### 一个测试：在 WSL 里输入

```bash
echo "Hello World" && ls / && whoami
```

>  是不是总听见kaliLinux？想玩 Kali 全量工具？等对 Linux 有了基础再上()，先去用 WSL + `sudo apt install` 装你需要的工具（如 `nmap`、`netcat`）。

<a id="git管理代码的必备技能"></a>
## Git：管理代码的必备技能

写代码/写文档迟早要多人协作，Git 就是干这个的。**本仓库就是一个 Git 仓库**，你可以直接实践：

<a id="最小流程"></a>
### 最小流程

```powershell
git add 文件名        # 把改动加入暂存区（git add -A 加全部）
git commit -m "改了什么"   # 提交一个版本
git push              # 推送到远程（GitHub）
git pull              # 拉取远程最新
git status            # 看当前状态
git log               # 看提交历史
```

<a id="三个区概念"></a>
### 三个区概念

```
工作区(你改的文件) → git add → 暂存区 → git commit → 本地仓库 → git push → GitHub
```

- `git status` 看文件在哪个区
- 改坏了可以用 `git checkout -- 文件` 撤销工作区改动（**会丢改动，慎用**）

<a id="新手常见坑"></a>
### 新手常见坑

- 忘记配置身份 → 提交报错 → 先 `git config --global user.name "你的名字"` 和 `user.email`
- `git push` 提示认证失败 → 用浏览器登录一次 GitHub（或配置 SSH 密钥）
- 不要提交大文件/敏感文件（密码、token），用 `.gitignore` 排除

<a id="网络基础速通"></a>
### 网络基础速通

不懂网络原理，Wireshark 抓的包就是天书。新生阶段知道下面这些就够了：

#### 核心概念

| 概念 | 解释 |
|---|---|
| IP 地址 | 设备在网络中的"门牌号"（如 `192.168.1.1`） |
| 端口 | 门牌号里具体到"哪个房间的门"（如 80=HTTP、443=HTTPS、22=SSH） |
| DNS | 把 `www.baidu.com` 翻译成 IP |
| HTTP/HTTPS | 网页传输协议，HTTPS 是加密版 |
| 数据包 | 网络上传输数据的"快递包裹" |

#### 两个命令

```powershell
ping baidu.com        # 测试网络通不通
nslookup baidu.com    # 查域名的 IP（DNS 查询）
```

#### 连接题目：用 nc（浏览器打不开不代表环境坏了）

很多题目（Pwn / Misc）用的是**原始 TCP 协议**，浏览器只会显示"服务器发送了无效的响应"——环境没坏，是你没用对工具。这时候要打开**《nc引入.md》**，学会用 nc 连接：

>nc 目标IP 端口

> **详见《nc引入.md》**：怎么装（Linux/WSL 用 `netcat-openbsd`，Windows 装 nmap 自带 `ncat`）、常用选项（`-lvnp` 监听、`-v` 详细、`-w` 超时）、配合 pwntools 写自动化交互脚本。**反复手动输入时，就该写脚本了。**

<a id="qa"></a>
##  Q&A
### Q：老大老大，网安是什么？
### A
>网安是网络安全的简称，全称是 **Cyber Security**。简单来说，就是保护网络系统中的硬件、软件和数据，不被破坏、泄露或非法篡改。
### Q：老大老大，我学了网安是不是就成为黑客了？可以破解软件以及使用"盒武器"了？
### A
>《**网络安全法**》《**个人信息保护法**》及**刑法修正案**(**九**)了解一下？
>不可以当黑客，但是红客是可以的(￣▽￣)"
### Q：那老大，我经常听见有人在谈论打CTF，CTF又是什么？
### A
>「CTF Capture The Flag」中文一般译作**夺旗赛**，在网络安全领域中指的是网络安全技术人员之间进行技术竞技的一种比赛形式。CTF 起源于 1996 年 DEFCON 全球黑客大会，以代替之前黑客们通过相发起真实攻击进行技术比拼的方式；其将安全相关的知识点抽象出来并加入到题目中，我们通过对知识点的理解认知，具体地进行实践来攻克题目
### Q：那老大，CTF都有什么方向呢？
### A
>有**Web、Reverse、Pwn、Crypto、Misc、Blockchain、OSINT、Forensics**(**web安全，逆向，二进制，密码学，杂项，区块链安全，开源情报，数据取证**)，当然还有近年来新出现的**AI安全**
### Q：老大能不能解释一下这些方向呢?
### A

>**Web 安全（Web）**
>着重于 Web 应用程序，框架，浏览器以及各类 Web 服务器的安全问题；挖掘 / 利用 / 研究各类 Web 系漏洞，探究其形成原理、利用方式及修补方案。题目常见的漏洞类型包括注入、XSS、文件包含、代码执行、上传、SSRF 等，选手通过漏洞直接或者间接拿到 shell 或者得到某些关键文件从而得到 Flag。 ——汪汪汪
>
>**逆向工程（Reverse）**
>研究各类操作系统，编译器，虚拟机的底层架构，以 Windows 和 Linux 为平台，学习可执行程序的逆向分析技术，如软件调试与破解，对已经编译完成的可执行文件进行分析，研究程序的行为和算法，然后以此为依据，计算出出题人想隐藏的 flag ——逆��
>
>**二进制漏洞（Pwn）**
>Pwn 在安全领域是「攻破」的意思。主要研究程序漏洞利用技术，例如栈溢出、堆管理器的漏洞利用和其他高阶技巧；挖掘和分析各类基于编译型语言的漏洞。二进制攻击涉及到栈溢出、堆溢出、格式化字符串漏洞等二进制漏洞，选手需要借助这些漏洞获取计算机权限，从而拿到 flag ——PWN!(指声音
>
>
>**密码学（Crypto）**
>密码学简单讲就古典密码和现代密码，当然大多数古典密码的题目目前都被划分到 MISC 中，目前的密码学反而更偏向现代密码学，常出现分组密码、流密码和公钥密码体制的考察，对初等数学、基本的数论有一定需求。选手通常被给予一个加密程序，抹去明文之后留下的加密过程和输出，要求选手通过密码体制的弱点来还原 flag。
>
>**杂项（Misc）**
>安全杂项涉及到古典密码学、编码、隐写术、电子取证、数据分析等广度极高的安全手段及利用方法，选手需要确定手段或者方法，反向的去破译取证从而拿到 flag，MISC 是 CTF 比赛中广度最高的方向，需要各个方向都有涉猎。 —— 嗯？题不知道丢哪？没事丢杂项就好！
>
>常见内容：编码，图片隐写，音频隐写，流量分析，文件修复，游戏交互。	
>
>**区块链安全（Blockchain）**
>分析智能合约（主要用 Solidity 编写），找到逻辑漏洞或权限缺陷。
>
>**开源情报（OSINT）**
>利用公开信息（搜索引擎、社交媒体、GitHub、WHOIS 等）搜集线索。
>
>**数字取证（Forensics）**
>从数字设备（硬盘、内存、手机）中恢复数据或追踪攻击痕迹。
>
>**AI 安全（AI Security）**
>这是近年新兴的热门方向。
>
>核心内容：攻击和防御人工智能/机器学习系统。
>随着 LLM的普及，AI 安全已经成为 CTF 中增速最快的方向之一。
### Q：那老大，我想参加CTF，CTF都有什么竞赛模式啊？
### A
>CTF 有个人赛和团队赛，在主流比赛中多为团队赛；
>
>CTF 赛制分多种，国内常见的为「 **解题模式** Jeopardy 」「 **攻防模式** | AWD (Attack With Defense) 」「 **静态攻防** AWDP (Attack With Defence Plus) 」一般分为线上线下两个阶段，线上通常采用 解题模式 ，线下通常为 CTF +( 理论 )+ AWD/AWDP 模式，具体看主办方安排。
>
>「 解题模式 Jeopardy 」目前大多数国内外 CTF 比赛的**主流形式**，选手自由组队参赛。>题目通常在比赛过程中陆续放出。解出一道题目后，提交题目对应的 flag 即可得分，比赛结束时分高者获胜。
>
>「 攻防模式 | AWD (Attack With Defense) 」通常为现场比赛，多数 CTF 决赛的比赛形式，选手自由组队参赛。每个队伍都有自己的 gamebox，其上运行着一些带有漏洞的服务。参赛战队需要找到漏洞对其他队伍 gamebox 发起攻击，也需要通过 patch 服务来加固自己的 gamebox。相比于解题模式，时间更短，比赛中更注重临场反应和解题速度，需要能够快速攻击目标主机的权限，考察团队多方面的综合安全能力。
>
>「 静态攻防 AWDP (Attack With Defence Plus) 」解题 + 加固赛，相比 AWD 赛制取消了 gamebox，主办方会根据出题人设置的脚本判断提交的 patch 是否有效（攻击则和解题模式类似），参赛队伍无法直接攻击其他队伍。每个回合，参赛队伍都会根据自己攻击和加固成功的题目（以及相应题目的解题队伍数）来得分，以累积得分作为排行依据。

>有疑惑？
>没关系，~~我们下面还有更迷糊的~~暂时了解就好啦，在 CTF 中，我们一般接触的最多的就是「 解题模式 Jeopardy 」。
### Q：什么是 WriteUp？
### A
>又称作**WP**，是记录 CTF 比赛中解题过程的文章，通常包含题目描述、解题思路、解题过程、源码分析、脚本分析等内容。当然你也可以简单理解为解题报告 —— 题解

### Q：我是零基础，大一加入社团会不会跟不上？
### A
>不会。这篇文档就是写给零基础的。社团的核心价值是**氛围和方向**——有人带你入坑，比你自己瞎摸索快十倍。跟上大部队节奏，每周动手做几道题就行。

### Q：我需要买什么配置的电脑？
### A
>**不需要特意买**。CTF 大部分题目普通笔记本都能跑（尤其入门阶段）。唯一建议内存 ≥ 16GB，方便跑虚拟机/WSL。

### Q：网安是不是对数学要求很高？
### A
>入门阶段**不高**。Misc/Web 基本不用数学；密码学和逆向后期会用到数论、线性代数、汇编，但那都是之后的事了。先动手，数学可以边学边补。

### Q：英语不好怎么办？
### A
>虽然网安资料 80% 是英文。但是**又不是不让你查**，学会"看不懂就查"：装个翻译插件（如沉浸式翻译），把常用报错和术语积累起来，半年后自然就顺了。

### Q：装软件一直失败/报错怎么办？
### A
>标准流程：复制完整报错信息（不是"**请复制这段信息**"） → 搜索引擎查报错 → 截图给社团群友问。**会问问题也是技能**——具体、有上下文的问题才能得到有效答案（详见文档目录里的《提问的智慧》）。

<a id="法律红线"></a>
## 法律红线

上文提了一嘴，这里展开说———**学网安≠当黑客**：

- 《网络安全法》：入侵他人系统、破坏数据都是违法
- 《个人信息保护法》：非法获取、买卖个人信息违法
- 《刑法》第 285 条：非法侵入计算机信息系统罪
- 《刑法》第 286 条：破坏计算机信息系统罪
- 就算"只是试试"，只要进入**未授权**的系统就算违法
- 未经授权，**不要**扫描、爆破、攻击任何不是你自己的系统
- 别人让你"帮忙看看某某网站"——先确认你有没有授权，没有就拒绝

> 记住：**攻防技术是"能力"，法律意识是"底线"**。红客和黑客的区别，就在使用目的的正当性与授权与否。
